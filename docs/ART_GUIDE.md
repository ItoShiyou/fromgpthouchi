# 本番イラストの入れ方（夜喫茶）

いまの絵はすべてコードで描いた仮の絵です。
**決まった場所に PNG を置くだけで、その部分だけが本番の絵に置き換わります**（コードの変更は不要）。
置いていない部分は、仮の絵のまま動き続けます。1 枚ずつ差し替えていけます。

```text
assets/art/yoru_kissa/
├── room/base.png           背景（壁・床・カウンター）
├── window/{id}.png         窓まわり（カーテンなど）
├── wall/{id}.png           壁に掛けるもの
├── light/{id}.png          照明
├── seat/{id}.png           ソファ席
├── table/{id}.png          テーブル
├── corner/{id}.png         店の隅（植物・レコード・傘立て…）
├── counter/{id}.png        カウンターの上の小物
├── visitors/{id}.png       客の似顔絵
└── icons/{id}.png          家具・メニュー・商品の小さなアイコン
```

`{id}` は下の一覧の ID です。ファイルを置いたら `flutter run` し直すだけで反映されます。

---

## 1. 店の絵（背景と家具）

### キャンバス

- **1080 × 1350 px（4:5）**、背景も家具も**全部同じ大きさ・同じ位置合わせ**の PNG
- 家具のファイルは、その家具以外の部分を**透明**にする（重ねて使うため）
- 背景 `room/base.png` は**窓ガラスの部分を透明**にする（外の空・雨・雪はアプリが描く）
- 縦長の端末では、この 4:5 の上に天井、下に床をアプリが描き足します。
  背景の**上端は壁の色、下端は床の色**で終わらせてください

### 照明・時間帯は描き込まない

- **昼間の、平らな明るさ**で描いてください
- 夕方・夜の暗さ、ランプのにじみ、ネオンの光は、絵の上にアプリが重ねます
  （夜の絵を描くと、夜にさらに暗くなってしまいます）

### 置き場所（キャンバスに対する割合）

アプリの仮の絵と同じ位置に描くと、客の座る位置と合います。

| 場所 | 範囲（左, 上 〜 右, 下） | メモ |
| --- | --- | --- |
| 窓 | 0.06, 0.08 〜 0.46, 0.44 | 背景では透明に。カーテンは窓の左右に |
| 壁のもの | 0.54, 0.08 〜 0.92, 0.44 | 時計・本棚・看板・ポスター |
| ソファ席 | 0.02, 0.54 〜 0.38, 0.73 | 客 1 人目がここに座る |
| テーブル | 中心 0.47, 0.72／幅 0.24 | 天板の上にカップ（湯気の演出が出る） |
| 店の隅 | 足元 0.585, 0.80 を中心に | 植物・レコード・傘立て |
| カウンター | 0.66, 0.54 〜 1.00, 0.84 | 背景に含める。上の小物は counter/ |
| 照明 | 天井中央 0.50, 0.14／床置きは 0.07 付近 | |
| 床（猫が寝ている） | 0.64, 0.935 付近 | ここは空けておく |

客が座る位置（頭の中心）：**0.16, 0.50**（ソファ）／**0.47, 0.54**（テーブル）／**0.80, 0.40**（カウンター）。
家具がこの位置の手前に来ないようにしてください（客が家具の奥に座っているように見える）。

## 2. 客の似顔絵

- **512 × 512 px、背景は透明**
- 胸から上（バストアップ）。**肩が下端に接する**ように。頭の中心はおよそ (0.50, 0.42)
- 店の中では、この絵がそのまま席に座ります。図鑑・一覧ではカードの中に入ります
- 未発見の間は、アプリが絵を影の色で塗りつぶしてシルエットにします（別に描く必要はありません）
- 全員を同じ顔の型で描かないこと（輪郭・目・眉・口・姿勢を人ごとに変える）

## 3. アイコン

- **256 × 256 px、背景は透明**、ものを 1 つだけ
- 線の太さを全アイコンでそろえる。影・グラデーションは付けない
- 置かなければ、判子風の一文字（卓・珈…）が出ます。一文字のまま出すのも可

## 4. 画風のルール

`docs/SPEC.md` の「ビジュアルと文言のルール」と同じです。要点だけ：

- 輪郭は**手で引いた線**（定規・完全な円にしない）。線の揺れは少しでよい
- 塗りは**平らな色＋紙の質感**。つるつるのグラデーションにしない
- 色は「夜の紺 × 紙のクリーム × 焦げ茶の木」。原色・蛍光色は使わない
- 人物は**それぞれ別の人**に見えること。全員が同じ笑顔にならないように

## 音の差し替え

`assets/audio/` の同じ名前のファイルを上書きすれば差し替わります（今は `tools/make_placeholder_audio.py` で作った仮の音）。

| ファイル | 用途 | 目安 |
| --- | --- | --- |
| `bgm_room.wav` | BGM を選んでいない時の「店の物音」 | 20〜60 秒のループ。とても小さく |
| `bgm_rain_piano.wav` | BGM：雨音とピアノ | ループ |
| `bgm_midnight_radio.wav` | BGM：深夜ラジオ | ループ |
| `se_coin.wav` | 会計 | 0.5 秒以内 |
| `se_stamp.wav` | 家具を置く・レシピを覚える | 0.3 秒以内 |
| `se_gacha.wav` | 余白くじ | 1 秒以内 |
| `se_paper.wav` | パネルを開く | 0.3 秒以内 |

ループは頭と尻がつながるように。形式は wav／mp3／m4a のどれでもよい（拡張子を変える場合は `lib/core/services/sound.dart` と content の `asset` を合わせる）。
